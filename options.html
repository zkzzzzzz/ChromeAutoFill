SmartFill — Question Matching Rules

Each rule fills a value into a matching input field. Give a CSS selector when you know the field's exact id (e.g. #kba1_response) — that's checked first and is the most reliable. Otherwise, leave it blank and use a match keyword: SmartFill scans nearby text (labels, placeholders, or a preceding question) for it, case-insensitively. A rule needs at least one of the two. Existing values are never overwritten.
